# 停电应急加油台

- 行业：石油（加油站台风夜停电应急场景）
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

1. **建档**：登记受影响油枪、停电开始时刻、纸单号范围。
2. **手工加油**：填写车牌后三位、枪号、升数、收款、纸单号；
   **重复单号或收款空缺自动挂入「待补录」**，先留待补录。
3. **复电匹配**：导入终端小票按单号匹配；**金额一致才核销，金额不符禁止核销**；
   终端无小票、待匹配单持续挂起。
4. **关班交接**：有任何未闭环单（待补录/待匹配/金额不符/无小票）**不能关班**；
   下一班填写承接原因后可继续处理。
5. **恢复营业**：设备自检与油枪复位**双双通过**才能确认恢复营业；
   确认后数据**冻结**，更正只能**另建带原因的更正版本**（原始单追加留痕、不覆盖）。

## 分层结构

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 数据 | `src/data` | 领域类型 `types.ts`、演示种子 `seed.ts` |
| 判定 | `src/domain/rules.ts` | 纯函数规则：校验、重复/空缺判定、金额核销、关班/恢复营业规则 |
| 保存 | `src/store/desk.ts` | Pinia 状态 + localStorage 持久化 + 流程编排 |
| 页面 | `src/components`、`src/App.vue` | 建档、手工台、小票匹配、自检/关班，仅负责交互展示 |

数据保存在浏览器 localStorage（`dfwl-outage-desk-v1`），可随时「重置为演示数据」。
